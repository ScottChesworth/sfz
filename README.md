# SFZ Tool Prototype

An experimental accessible SFZ instrument editor built with Rust and wxDragon.

The goal is a lightweight cross-platform GUI using native controls, with screen-reader-friendly workflows for NVDA on Windows and VoiceOver on macOS.

## Current Status

This is an early GUI prototype. It currently exercises the main accessibility-sensitive controls: region and validation lists, labelled text fields, a choice control, a checkbox, and buttons.

## Run Locally

```powershell
cargo run
```
